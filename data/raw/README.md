# data/raw

Raw downloads (boundaries, raster subsets) are stored here and are not tracked by git. Only this README is versioned.

Each source, its URL and access method are documented in `docs/phase0_results.md`. Raw files can be regenerated with:

```
python -m lagos_heat.phase0_check
```

run from the `src/` directory, or with `src/` on `PYTHONPATH`.
